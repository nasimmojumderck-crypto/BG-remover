# 🖼️ ব্যাকগ্রাউন্ড রিমুভার

ইমেজ আপলোড করলে AI (ISNet) নিজে থেকেই সাবজেক্ট ডিটেক্ট করে ব্যাকগ্রাউন্ড সরিয়ে ট্রান্সপারেন্ট PNG দেয়।

## সেটআপ

```bash
pip install -r requirements.txt
python app.py
```

তারপর ব্রাউজারে খুলুন: http://127.0.0.1:5000

## ব্যবহার

1. ইমেজ ক্লিক করে বা ড্র্যাগ করে আপলোড করুন
2. AI অটোমেটিক ব্যাকগ্রাউন্ড রিমুভ করবে
3. "ডাউনলোড করুন" বাটনে ক্লিক করে PNG সেভ করুন

## নোট

- প্রথমবার চালালে AI মডেল (~১৭০ MB) অটো ডাউনলোড হবে, একবারই লাগবে
- সাপোর্টেড ফরম্যাট: PNG, JPG, JPEG, WEBP (সর্বোচ্চ ১৬ MB)
- সার্ভার শুধু লোকাল কম্পিউটারে চলে (127.0.0.1:5000)
